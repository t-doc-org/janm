# Objectifs de l'examen

## HTML
- Connaître la structure d'une page HTML (`<!DOCTYPE html>`, `<html>`, `<head>`, `<body>`) et savoir quelles balises se placent dans le `<head>` (`<meta>`, `<title>`) ou dans le `<body>`
- Utiliser les titres `<h1>` à `<h6>` en respectant leur hiérarchie, les paragraphes `<p>` et le retour à la ligne `<br>`
- Créer des listes numérotées `<ol>` et à puces `<ul>` avec leurs éléments `<li>`
- Insérer une image avec la balise `<img>` et ses attributs `src`, `width` et `height`
- Créer un lien avec la balise `<a>` et ses attributs `href` et `target`
- Créer et compléter un tableau avec les balises `<table>`, `<tr>`, `<th>` et `<td>`, par exemple en y ajoutant une ligne ou une colonne
- Repérer et corriger les erreurs d'un code HTML : balise non fermée ou mal imbriquée, attribut mal écrit, balise placée au mauvais endroit

## CSS
- Écrire du CSS dans la balise `<style>` placée dans le `<head>`
- Écrire une règle CSS correcte : sélecteur, accolades, propriétés et valeurs, point-virgule à la fin de chaque déclaration
- Utiliser les propriétés CSS vues en cours (à connaitre par coeur : `color`, `background-color`, `font-family`, `font-size`, `text-align`) avec des valeurs correctes.
- Utiliser un sélecteur de type pour mettre en forme toutes les balises d'un même type
- Définir une classe dans le CSS et l'appliquer à une ou plusieurs balises HTML avec l'attribut `class`
- Prédire le résultat lorsqu'un sélecteur de type et un sélecteur de classe s'appliquent au même élément

## Bootstrap
- Utiliser les classes `container`, `row` et `col` afin de correctement disposer des éléments sur plusieurs lignes et plusieurs colonnes
